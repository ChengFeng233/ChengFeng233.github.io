[GitHub repository](https://github.com/ChengFeng233/USTC_ROBOGAME2025_CV)

This repository contains Python and OpenCV code for the robot-vision component of USTC ROBOGAME 2025. It includes camera calibration and distortion correction, AprilTag-based localization, and color and blink detection. The competition scripts combine these signals and communicate with the robot controller over a serial link.
